# python-octo-journey.github.io

Early Python learning scripts — fibonacci, password generation, IoT experiments.

## The problem

You are collecting small Python exercises while learning syntax and basic algorithms.

## What it does

Standalone `.py` files: fibonacci sequence, password generator, IoT snippet — run individually, not as a package.

## Install

```bash
git clone https://github.com/irachrist1/python-octo-journey.github.io.git && cd python-octo-journey.github.io
python3 "fibonnanci sequence.py"
python3 "generate new pass.py"
```

## How it works

- **One script per concept.** Each file teaches one idea — no project structure overhead.
- **Learning archive.** Filename typos preserved — journey over polish.
- **GitHub Pages repo name.** Originally intended for hosted Python learning notes; scripts are the artifact.
